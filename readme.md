# 🛡️ TSU CyberSecurity



Веб-платформа для интерактивного изучения современных киберугроз, методологий атак и способов защиты. Проект разработан как образовательный ресурс с элементами симуляции реальных угроз в безопасной среде.

---

## 🚀 Основные возможности

*   **Интерактивные статьи**: Разбор OWASP Top 10 и социально-технических угроз, включающих как социальную инженерию, так и критические ошибки проектирования.
*   **Симуляция атаки:** Пользователи могут собственноручно попробовать исполнить взлом в безопасной среде нашего сайта, также ниже они могут прочесть раздел "Защита и предотвращение" и быть более осведомленным.
*   **Пасхалки и сценарии**: Система включает скрытые сценарии (BSOD-эффекты и ловушки), которые срабатывают при попытках "взлома" интерфейса.
*   **Интуитивный интерфейс**: Интерфейс сайта интуитивно понятен даже новичку, на которых он и рассчитан. Поддержка русского и английского языков.
*   **Новости:** Для повышения осведомленности на сайте есть вкладка с новостями, где собраны ведущие порталы, содержащие новости кибербезопасности.
*  **Поиск:** На сайте реализован поиск по Wikipedia, который при вводе запроса перебрасывает пользователя на соответствующую вкладку в Wikipedia. 
---

## 🏛 Архитектурные решения

- **Локализация на уровне констант**: Тексты вынесены в отдельные структуры данных, что позволяет переключать язык интерфейса без перезагрузки страницы (Client-side i18n).
    
- **Симуляция механизмов WAF (Web Application Firewall)**: В поисковой строке реализована логика перехвата сигнатур XSS-атак с использованием регулярных выражений. Система в реальном времени анализирует ввод на наличие опасных тегов (`<script>`) и функций (`alert`), имитируя работу реальных систем защиты и предоставляя обучающий фидбек пользователю.
    
- **Слоистая сборка Docker**: Использование Multi-stage builds позволяет разделить процесс компиляции (Node.js) и этап раздачи контента (Nginx), что уменьшает итоговый размер образа на 90%.

## 🛠 Запуск в режиме разработки (Local Development)

Для внесения изменений в код и тестирования в реальном времени:

1. **Клонирование**: `git clone <ссылка_на_репозиторий>`
    
2. **Среда**: Убедитесь, что у вас установлен Node.js v20+.
	
3. **Установка зависимостей**:
    
    Bash
    
    ```
    npm install
    ```
    
4. **Запуск dev-сервера**:
    
    Bash
    
    ```
    npm run dev
    ```
    
5. **Сборка production-версии**:
    
    Bash
    
    ```
    npm run build
    ```
6. **Переход на сайт:** зайдите на localhost:3000.

## 🐳 Запуск в Docker

1. **Клонирование**: `git clone <ссылка_на_репозиторий>`
    
2. **Среда**: Убедитесь, что у вас установлен Docker.
    
3. **Запуск через Docker (Рекомендуется)**:
    
    Bash
    
    ```
    docker build -t tsu-cyber-security .
    docker run -d -p 8080:80 --name tsu-cyber-security tsu-cyber-security

    ```
    
4. **Сайт**: Откройте `localhost:8080` в браузере.
